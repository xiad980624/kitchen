# 小家厨房待办

以下项目按使用优先级维护；不与当前账号和同步改动混在同一个分支。

## 下一批

- [ ] **完成菜单后确认消耗库存**：列出本次菜单食材，允许调整实际消耗量后再扣减冰箱库存。
- [ ] **待购项买入后入库**：食材可填写买入数量并加入冰箱；非食材只标记买完。

## 后续体验优化

- [ ] **真实临期提醒**：按今天、三天内和已过期排序，并在用户授权后发送本地通知。
- [ ] **做菜模式**：大字步骤、前后切换、步骤计时与屏幕常亮。
- [ ] **常用菜单模板**：复制上周、工作日/周末模板和剩菜安排。
- [ ] **图片分离同步**：将菜谱封面和步骤图片上传到服务器媒体接口，不把大图片塞进同步快照。
- [ ] **双设备验收**：两个账号完成邀请、菜谱/库存/日历同步、冲突处理和图片同步验证。
- [ ] **服务端运维**：定期数据库备份、图片备份和容器重启后的持久化检查。
